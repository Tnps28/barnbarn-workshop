# กลุ่ม H · ระดับสูง (Level 2)

> กลุ่มนี้ไม่ควรอยู่ในเมนูของวันเรียนปกติ — ใช้กับคนที่เร็วมาก หรือเก็บไว้สอนคลาสต่อยอด

## H1 · QR ประจำจุด เปิดมาเห็นเฉพาะหน้าสั่ง  **[สูง]**
**ต้องมีก่อน:** A1
**แตะไฟล์:** `server.js` `public/index.html` `public/admin.html`

```
อ่าน CLAUDE.md เป็นบริบทก่อน
ทำโหมด QR ประจำจุด (โต๊ะ / บูธ / สาขา):
- เปิดลิงก์แบบ /?t=<รหัสจุด> แล้วเว็บเข้าโหมดคีออสก์: ไม่มีเมนูอื่น มีแต่หน้าสั่งของ
- ออเดอร์ที่สั่งจากลิงก์นั้นติดรหัสจุดมาด้วย หลังบ้านเห็นว่ามาจากจุดไหน
- หลังบ้านสร้าง QR ของแต่ละจุดแล้วสั่งพิมพ์ได้
- ในโหมดนี้ห้ามมีทางเข้าหน้าหลังบ้านโดยเด็ดขาด แม้จะพิมพ์ /admin ตรง ๆ ก็ต้องยังต้องใส่รหัส
```
**ทดสอบ:** เปิดลิงก์คีออสก์แล้วพยายามไปหน้าอื่น → ไปไม่ได้ · สั่งของ → หลังบ้านเห็นรหัสจุด
**ถอดมาจาก:** Seed POS (`?t=` kiosk mode)

## H2 · ติดตั้งเป็นแอปบนมือถือ (PWA)  **[สูง]**
**ต้องมีก่อน:** ฐาน
**แตะไฟล์:** `public/manifest.webmanifest` `public/sw.js` `public/*.html`

```
อ่าน CLAUDE.md เป็นบริบทก่อน
ทำให้เว็บนี้ติดตั้งเป็นแอปบนหน้าจอมือถือได้:
1. เพิ่ม manifest.webmanifest: ชื่อ ไอคอน สีธีม โหมดเต็มจอ
2. สร้างไอคอนขนาด 192 และ 512 จากอีโมจิโลโก้
3. เพิ่ม service worker ที่แคชไฟล์ CSS/JS แต่ **หน้า HTML ต้องเอาจากเน็ตก่อนเสมอ**
   (network-first) ไม่งั้นคนที่ติดตั้งไว้จะเห็นเว็บเวอร์ชันเก่าค้างตลอด
4. มีเลขเวอร์ชันแคชที่บอกวิธีเปลี่ยนเวลาปล่อยของใหม่
เขียนวิธีทดสอบว่าอัปเดตแล้วเครื่องที่ติดตั้งไว้เห็นของใหม่จริง
```
**ทดสอบ:** ติดตั้งบนมือถือ → แก้ข้อความ → deploy → เปิดแอปอีกครั้งต้องเห็นของใหม่
**ถอดมาจาก:** Seed POS (`manifest.webmanifest` + `assets/sw.js`)

## H3 · ใช้งานต่อได้ตอนเน็ตหลุด แล้วค่อยซิงก์  **[สูง]**
**ต้องมีก่อน:** H2, A1
**แตะไฟล์:** `public/*` `server.js`

```
อ่าน CLAUDE.md เป็นบริบทก่อน
ทำให้ใช้งานต่อได้ตอนเน็ตหลุด (สำหรับหน้าร้านที่ไวไฟไม่นิ่ง):
- เก็บสำเนาข้อมูลไว้ในเครื่อง ใช้แสดงผลได้แม้ไม่มีเน็ต
- ทำงานที่เปลี่ยนข้อมูล ให้เก็บเป็น "รายการรอส่ง" แล้วส่งเองเมื่อเน็ตกลับมา
- มีป้ายบอกสถานะชัด ๆ: ออนไลน์ / ออฟไลน์ (มี n รายการรอส่ง)
- ถ้าสองเครื่องแก้ของเดียวกันตอนออฟไลน์ ให้ตัดสินด้วยเวลาที่แก้ล่าสุด และเก็บ log ไว้ตรวจ
เตือนล่วงหน้าด้วยว่าส่วนไหนของระบบจะยุ่งขึ้นหลังทำอันนี้
```
**ทดสอบ:** ปิดเน็ต → สั่ง 2 ออเดอร์ → เปิดเน็ต → ทั้งสองขึ้นระบบครบ ไม่ซ้ำ ไม่หาย
**ถอดมาจาก:** Seed POS (`17-sync.js` + Durable Object / Render sync server)
**เตือน:** อันนี้ยากที่สุดในคลังทั้งหมด อย่าเริ่มถ้าเว็บหลักยังไม่นิ่ง

## H4 · บันทึกเวลาเข้างาน + คิดค่าแรง  **[สูง]**
**ต้องมีก่อน:** D8
**แตะไฟล์:** `db.js` `server.js` `public/admin.html`

```
อ่าน CLAUDE.md เป็นบริบทก่อน
เพิ่มหน้า "เข้างาน" แยกออกมาจากหน้าผู้จัดการ:
- เลือกวัน เลือกคน ใส่ช่วงเวลา (เช่น 10:00-18:00) และมีพักหรือไม่ (ถ้ามีใส่ช่วงพัก)
- คำนวณชั่วโมงสุทธิ × ค่าแรงต่อชั่วโมง
- พนักงานเห็นเฉพาะของตัวเอง หัวหน้าเห็นทุกคนและแก้ได้
- สรุปรายเดือนต่อคน ดาวน์โหลดเป็น CSV ได้
```
**ทดสอบ:** ใส่ช่วงพักคาบเกี่ยวเวลาทำงาน → ชั่วโมงสุทธิยังถูก
**ถอดมาจาก:** Seed POS (แท็บเข้างาน)

## H5 · นับผู้เข้าชม / ดูว่ามาจากช่องทางไหน  **[บ้าน]**
**ต้องมีก่อน:** ฐาน
**แตะไฟล์:** `server.js` `db.js` `public/admin.html`

```
อ่าน CLAUDE.md เป็นบริบทก่อน
เพิ่มการนับผู้เข้าชมแบบง่าย ๆ ที่ไม่ต้องพึ่งบริการภายนอก:
- นับจำนวนครั้งที่เปิดแต่ละหน้า ต่อวัน
- ถ้าลิงก์มีพารามิเตอร์ ?from=fb / ?from=line ให้แยกนับตามช่องทาง
- แสดงเป็นกราฟแท่ง 30 วันล่าสุดในหน้าหลังบ้าน
- **ห้ามเก็บ IP หรือข้อมูลที่ระบุตัวบุคคลได้** เก็บแค่ตัวเลขรวม
- เก็บย้อนหลังแค่ 90 วัน แล้วลบของเก่าอัตโนมัติ กันฐานข้อมูลบวม
```
**ทดสอบ:** เปิดเว็บ 5 ครั้ง → ตัวเลขขึ้น 5 · เปิดด้วย ?from=line → แยกช่องทางถูก
**ถอดมาจาก:** ใหม่
