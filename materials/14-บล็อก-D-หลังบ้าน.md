## D1 · แก้ข้อความทุกจุดในเว็บจากหลังบ้าน  **[ห้อง]**
**ต้องมีก่อน:** ฐาน
**แตะไฟล์:** `db.js` `public/admin.html` `public/*.html`

> ฐานทำเรื่องนี้ไว้แล้วสำหรับข้อความหลัก บล็อกนี้คือ "ขยายให้ครบทุกจุด"

```
อ่าน CLAUDE.md เป็นบริบทก่อน
ตอนนี้ยังมีข้อความบางจุดที่ฝังอยู่ในไฟล์ HTML แก้จากหลังบ้านไม่ได้
ช่วยไล่หาข้อความที่ผู้ใช้เห็นทั้งหมดใน public/*.html ที่ยังไม่ได้อยู่ใน content
แล้วย้ายมาเป็น key ใน content ของ seed() พร้อมเพิ่มช่องแก้ในหน้าหลังบ้าน
(อย่าลืมเพิ่มชื่อ key ลงในตัวแปร CONTENT_FIELDS ของ admin.html ด้วย)
เป้าหมาย: เจ้าของร้านแก้ข้อความทุกคำบนเว็บได้เองโดยไม่ต้องเปิดโค้ดอีกเลย
```
**ทดสอบ:** แก้ข้อความปุ่มจากหลังบ้าน → หน้าเว็บเปลี่ยนตามโดยไม่ต้อง deploy
**ถอดมาจาก:** เว็บตลาดคุณปู่ (`Content` model)
**ทำไมสำคัญ:** นี่คือบล็อกที่ทำให้คำสัญญา "อัปเกรดต่อเองได้ตลอด" เป็นจริง โดยไม่ต้องพึ่ง AI อีก

## D2 · คลังรูปในฐานข้อมูล + ย่อรูปอัตโนมัติ  **[ห้อง]**
**ต้องมีก่อน:** ฐาน
**แตะไฟล์:** `db.js` `server.js` `public/admin.html`

> ฐานย่อรูปและเก็บรูปไว้ให้แล้ว บล็อกนี้เพิ่ม "หน้าคลังรูป" ให้จัดการได้

```
อ่าน CLAUDE.md เป็นบริบทก่อน
เพิ่มแท็บ "คลังรูป" ในหลังบ้าน:
- แสดงรูปทั้งหมดที่เคยอัป เป็นตาราง thumbnail พร้อมขนาดไฟล์
- เลือกรูปเก่ามาใช้ซ้ำได้ ไม่ต้องอัปใหม่
- ลบรูปที่ไม่ได้ใช้ได้ แต่ต้องเตือนก่อนถ้ารูปนั้นยังถูกใช้อยู่ในรายการไหน
- แสดงพื้นที่รวมที่รูปกินไป
```
**ทดสอบ:** ลบรูปที่ยังใช้อยู่ → ต้องมีคำเตือน ไม่ใช่ลบเงียบ ๆ
**ถอดมาจาก:** เว็บตลาดคุณปู่ (`/images`, `/upload`)

## D3 · แดชบอร์ดสรุปยอด + สถิติ  **[ห้อง]**
**ต้องมีก่อน:** A1 หรือ B1
**แตะไฟล์:** `server.js` `public/admin.html`

```
อ่าน CLAUDE.md เป็นบริบทก่อน
เพิ่มแท็บ "ภาพรวม" เป็นแท็บแรกของหลังบ้าน แสดง:
- ตัวเลขใหญ่ 4 ตัว: ออเดอร์/ใบจองวันนี้ · รอดำเนินการ · ยอดรวมเดือนนี้ · รายการที่ขายดีที่สุด
- รายการ "สิ่งที่ต้องทำวันนี้" เช่น สลิปรอตรวจ ออเดอร์ที่ยังไม่จัด
คำนวณจากข้อมูลจริงในฐานข้อมูล ห้ามใส่ตัวเลขสมมติ
ถ้ายังไม่มีข้อมูล ให้ขึ้นว่า "ยังไม่มีข้อมูล" ไม่ใช่เลข 0 ลอย ๆ
```
**ทดสอบ:** เว็บใหม่ยังไม่มีออเดอร์ → ไม่พังและไม่โชว์เลขมั่ว
**ถอดมาจาก:** Bookly (`/api/admin/summary`) · เว็บตลาดคุณปู่ (หน้าภาพรวม)

## D4 · Export Excel ภาษาไทยไม่เพี้ยน  **[ห้อง]**
**ต้องมีก่อน:** A1 หรือ B1
**แตะไฟล์:** `server.js` `public/admin.html`

```
อ่าน CLAUDE.md เป็นบริบทก่อน
เพิ่มปุ่มดาวน์โหลดรายชื่อ/ออเดอร์เป็นไฟล์ CSV ที่เปิดใน Excel แล้วภาษาไทยอ่านออก
- ใส่ BOM (﻿) ไว้หน้าไฟล์ ไม่งั้นภาษาไทยจะเพี้ยน
- ครอบค่าที่มีลูกน้ำหรือขึ้นบรรทัดใหม่ด้วยเครื่องหมายคำพูด
- ตั้งชื่อไฟล์เป็น <ชื่อร้าน>-<วันที่>.csv
- กรองก่อนดาวน์โหลดได้: ช่วงวันที่ และสถานะ
```
**ทดสอบ:** เปิดไฟล์ใน Excel บนเครื่อง Windows → ภาษาไทยไม่เป็นตัวประหลาด
**ถอดมาจาก:** Bookly

## D5 · แก้ไข / ยกเลิก / ลบ + ซ่อมที่นั่งที่หลุด  **[บ้าน]**
**ต้องมีก่อน:** B1
**แตะไฟล์:** `server.js` `public/admin.html`

```
อ่าน CLAUDE.md เป็นบริบทก่อน
ในหลังบ้าน ให้แก้ใบจองได้: เปลี่ยนรอบ เปลี่ยนจำนวนคน แก้ชื่อ/เบอร์ ยกเลิก และลบ
ทุกครั้งที่เปลี่ยนจำนวนคนหรือรอบ ต้องคำนวณที่นั่งใหม่ให้ถูก
เพิ่มปุ่ม "ตรวจและซ่อมที่นั่ง" ที่ไล่นับที่นั่งใหม่จากใบจองจริงทั้งหมด
เผื่อกรณีข้อมูลเพี้ยนจากการแก้มือ
```
**ทดสอบ:** ย้ายคนจากรอบ A ไป B → ที่นั่งทั้งสองรอบถูกต้อง
**ถอดมาจาก:** Bookly (`/edit`, `repair-seats`)

## D6 · เฝ้าดูพื้นที่ฐานข้อมูล 512MB  **[บ้าน]**
**ต้องมีก่อน:** ฐาน
**แตะไฟล์:** `db.js` `server.js` `public/admin.html`

```
อ่าน CLAUDE.md เป็นบริบทก่อน
เพิ่มการ์ด "พื้นที่ฐานข้อมูล" ในหลังบ้าน:
- แสดงพื้นที่ที่ใช้ไป / 512MB เป็นแถบสี
- แยกให้เห็นว่ารูปกินไปเท่าไร ข้อมูลกินเท่าไร (รูปมักกินเกิน 90%)
- ถ้าเกิน 70% ให้ขึ้นคำเตือนสีส้มพร้อมปุ่มลัดไปหน้าคลังรูป
- แนะนำ 3 ทางแก้: ลบข้อมูลทดสอบ · ลบรูปที่ไม่ใช้ · ย่อรูปให้เล็กลงก่อนอัป
```
**ทดสอบ:** ตัวเลขที่แสดงใกล้เคียงกับที่เห็นในหน้า Atlas
**ถอดมาจาก:** Bookly (`getStorageStats`)
**ทำไมสำคัญ:** ฐานข้อมูลฟรีเต็มแล้วเว็บจะพังเงียบ ๆ ไม่มีใครเตือน

## D7 · สำรองข้อมูลทั้งฐาน + กู้คืน  **[บ้าน]**
**ต้องมีก่อน:** ฐาน
**แตะไฟล์:** `server.js` `public/admin.html`

```
อ่าน CLAUDE.md เป็นบริบทก่อน
เพิ่มปุ่มในหลังบ้าน 2 ปุ่ม:
1. "ดาวน์โหลดข้อมูลสำรอง" — ดึงข้อมูลทั้งหมดออกมาเป็นไฟล์ JSON ไฟล์เดียว
2. "กู้คืนจากไฟล์" — อัปไฟล์สำรองกลับเข้าไป
   ต้องให้พิมพ์คำว่า กู้คืน ยืนยันก่อน เพราะจะทับข้อมูลปัจจุบันทั้งหมด
เตือนให้ดาวน์โหลดสำรองไว้ก่อนทุกครั้งที่จะทำอะไรเสี่ยง ๆ
```
**ทดสอบ:** ดาวน์โหลด → ลบรายการ 1 อัน → กู้คืน → รายการกลับมา
**ถอดมาจาก:** Seed POS (ไฟล์สำรองก่อนอัปเดตทุกครั้ง)

## D8 · ผู้ใช้หลายคน + สิทธิ์เป็นระดับ  **[สูง]**
**ต้องมีก่อน:** ฐาน
**แตะไฟล์:** `db.js` `server.js` `public/admin.html`

```
อ่าน CLAUDE.md เป็นบริบทก่อน
เปลี่ยนจากรหัสผ่านเดียวทั้งร้าน เป็นผู้ใช้หลายคน แต่ละคนมีรหัสของตัวเอง:
- 3 ระดับ: พนักงาน (ดูและจัดการออเดอร์) · หัวหน้า (+ ดูยอดขาย) · เจ้าของ (ทุกอย่าง + จัดการผู้ใช้)
- บันทึกว่าใครทำอะไรไว้ในแต่ละรายการ เพื่อตามเรื่องได้ถ้ามีปัญหา
- ตรวจสิทธิ์ที่ฝั่งเซิร์ฟเวอร์เสมอ ห้ามตรวจแค่ซ่อนปุ่มบนหน้าเว็บ
- เก็บ ADMIN_PASSWORD เดิมไว้เป็นทางเข้าฉุกเฉินของเจ้าของ
```
**ทดสอบ:** ล็อกอินเป็นพนักงานแล้วยิง API ของเจ้าของตรง ๆ → ต้องถูกปฏิเสธ
**ถอดมาจาก:** Seed POS (Junior / Senior / Manager)

## D9 · ร้านค้าหลายเจ้า — สมัคร รออนุมัติ พักร้าน จัดลำดับ  **[สูง]**
**ต้องมีก่อน:** ฐาน (+ A1 ถ้าจะให้สั่งของได้)
**แตะไฟล์:** `db.js` `server.js` `public/admin.html` (+ `public/apply.html`)

```
อ่าน CLAUDE.md เป็นบริบทก่อน
ทำให้เว็บนี้รวมหลายร้านไว้ด้วยกัน (แบบตลาดนัด):
- shop: { id, name, owner, phone, line, facebook, about, image, status, order }
  status = pending / active / paused
- หน้า /apply ให้ร้านกรอกสมัครเอง เข้าคิวเป็น pending
- หลังบ้าน: อนุมัติ / ปฏิเสธ / พักร้าน / ลากจัดลำดับที่แสดง / แก้ข้อมูลร้าน
- item แต่ละชิ้นผูกกับ shopId และหน้าแรกกรองตามร้านได้
ร้านที่ยังไม่อนุมัติหรือถูกพัก ต้องไม่โผล่บนหน้า public เลย
```
**ทดสอบ:** สมัครร้านใหม่ → ยังไม่เห็นบนหน้าแรก → อนุมัติแล้วจึงเห็น
**ถอดมาจาก:** เว็บตลาดคุณปู่ (`/shops`, `/shops/apply`)
