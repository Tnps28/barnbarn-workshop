# ฐานเว็บร้าน — สตาร์ทเตอร์ของคลาส "พาทำเว็บไปด้วยกัน"

เว็บที่ **รันได้จริงตั้งแต่นาทีแรก** สำหรับร้านเล็ก ๆ
หน้าแรก · รายการสินค้า/บริการ · หน้ารายละเอียด · หลังบ้านแก้ข้อความและรูปเองได้ · นโยบายความเป็นส่วนตัว
รันฟรีทั้งหมด: **Render** (โฮสต์) + **MongoDB Atlas** (ฐานข้อมูล) + **cron-job.org** (กันเว็บหลับ)

> เว็บนี้ยังไม่มีระบบขาย ระบบจอง หรือระบบรับเงิน — พวกนั้นเป็น **"บล็อก"** ที่หยิบมาต่อทีหลัง
> ดูรายการบล็อกทั้งหมดในโฟลเดอร์ `บล็อก/`

---

## ลองรันในเครื่องก่อน (3 คำสั่ง)

```bash
npm install
cp .env.example .env        # แล้วเปิด .env ใส่ ADMIN_PASSWORD ของตัวเอง
node server.js
```

เปิด http://localhost:3000 — หลังบ้านอยู่ที่ http://localhost:3000/admin

ตอนยังไม่ได้ต่อฐานข้อมูล เว็บจะเก็บข้อมูลลงไฟล์ `data/db.json` ให้ชั่วคราว **ใช้ทดสอบเท่านั้น**

---

## เอาขึ้นออนไลน์ 4 ขั้น

1. **GitHub** — อัปไฟล์ทั้งหมด (ลากไฟล์ที่อยู่ *ข้างใน* โฟลเดอร์ ไม่ใช่ลากตัวโฟลเดอร์)
2. **MongoDB Atlas** — สร้าง cluster ฟรี → คัดลอก connection string
3. **Render** — New Web Service → เชื่อม repo
   - Build Command: `npm install`
   - Start Command: `node server.js`
   - Environment Variables: `ADMIN_PASSWORD`, `MONGODB_URI`
4. **cron-job.org** — ตั้งให้ยิงมาที่ `https://ชื่อเว็บ.onrender.com/health` ทุก 10 นาที

ขั้นตอนละเอียดพร้อมภาพอยู่ในสไลด์ **"คู่มือเอาเว็บขึ้นออนไลน์ ทีละขั้น"**

## แก้เว็บให้เป็นของตัวเอง

**วิธีที่ 1 — ไม่ต้องแตะโค้ดเลย** (แนะนำ)
เข้า `/admin` แล้วแก้ได้เลย: ชื่อร้าน โลโก้ สี ข้อความทุกจุด ข้อมูลติดต่อ รายการสินค้า รูปภาพ
รูปที่อัปจะถูกย่อขนาดให้อัตโนมัติ

**วิธีที่ 2 — สั่ง AI แก้โค้ด**
เปิดโฟลเดอร์นี้ใน Claude แล้วก๊อปพรอมต์จาก `prompts.md` ไปวางทีละอัน
เริ่มด้วยประโยคนี้เสมอ: *"อ่าน CLAUDE.md เป็นบริบทก่อน แล้ว…"*

---

## ⚠️ ความปลอดภัย — อ่านให้ครบ

- **ห้ามอัปไฟล์ `.env` ขึ้น GitHub** — `.gitignore` กันไว้แล้ว แชร์ได้แค่ `.env.example`
- เปลี่ยน `ADMIN_PASSWORD` เป็นรหัสของตัวเองที่เดายาก **ก่อน**เปิดให้คนอื่นใช้
- หน้า `/admin` ไม่มีลิงก์จากหน้า public โดยตั้งใจ — อย่าเพิ่มลิงก์เข้าไป
- หน้า `/privacy` เป็นแบบร่าง ต้องแก้ข้อความในวงเล็บเหลี่ยมให้ตรงกับร้านจริงก่อนเปิดใช้
- ลบรายการทดสอบทิ้งก่อนเปิดให้ลูกค้าจริงใช้

## โครงไฟล์

```
server.js            เส้นทาง (routes) ทั้งหมด
db.js                ชั้นข้อมูล — Mongo หรือไฟล์ JSON, ข้อมูลตั้งต้น, รูปภาพ
public/
  index.html         หน้าแรก (hero + การ์ดรายการ + เกี่ยวกับเรา + ติดต่อ)
  item.html          หน้ารายละเอียดของแต่ละรายการ
  admin.html         หลังบ้าน (ล็อกอินด้วยรหัสผ่าน)
  privacy.html       นโยบายความเป็นส่วนตัว (แบบร่าง — ต้องแก้)
  css/styles.css     สีและหน้าตาทั้งหมด
CLAUDE.md            บริบทสำหรับสั่ง AI แก้โค้ด + กติกาที่ห้ามพัง
prompts.md           พรอมต์ก๊อปวาง เรียงตามลำดับที่ใช้จริงในวันเรียน
.env.example         รายการตัวแปรที่ต้องตั้ง
```
