## F1 · อีเมลยืนยันอัตโนมัติ (Brevo) + ใช้แทน OTP  **[ห้อง]**
**ต้องมีก่อน:** A1 หรือ B1
**แตะไฟล์:** `server.js` `.env.example` (+ ไฟล์ใหม่ `services/email.js`)

```
อ่าน CLAUDE.md เป็นบริบทก่อน
เพิ่มการส่งอีเมลยืนยันอัตโนมัติ:
1. สร้าง services/email.js ที่ส่งผ่าน Brevo HTTP API (ห้ามใช้ SMTP — โฮสต์ฟรีบล็อก)
   อ่านคีย์จาก environment variables: BREVO_API_KEY และ EMAIL_USER
2. ส่งอีเมลตอน: สั่ง/จองสำเร็จ และตอนแอดมินยืนยันรับเงิน
3. เนื้ออีเมลใส่: ชื่อลูกค้า เลขที่บิล รายการ ยอด วันเวลา และวิธีติดต่อร้าน
4. ถ้ายังไม่ได้ตั้งคีย์ ให้ข้ามการส่งไปเงียบ ๆ แต่เขียน log ไว้ — ห้ามทำให้การจองล้มเหลว
5. เพิ่ม BREVO_API_KEY และ EMAIL_USER ลงใน .env.example ด้วย
```
**ทดสอบ:** ลบคีย์ออกแล้วจอง → การจองยังสำเร็จ แค่ไม่มีอีเมล
**ถอดมาจาก:** Bookly (`services/email.js`)
**อย่าลืม:** ต้องยืนยันอีเมลผู้ส่งใน Brevo (Senders) ก่อน ไม่งั้นส่งไม่ออกทั้งระบบ

## F2 · แจ้งเตือนแอดมินทันทีเมื่อมีออเดอร์ใหม่  **[ห้อง]**
**ต้องมีก่อน:** F1
**แตะไฟล์:** `server.js` `services/email.js` `public/admin.html`

```
อ่าน CLAUDE.md เป็นบริบทก่อน
ทุกครั้งที่มีออเดอร์/ใบจองใหม่เข้ามา ให้ส่งอีเมลแจ้งเจ้าของร้านทันที
- ตั้งอีเมลผู้รับได้จากหน้าหลังบ้าน (ใส่ได้หลายคน คั่นด้วยลูกน้ำ)
- หัวเรื่องอ่านแล้วรู้เรื่องทันทีโดยไม่ต้องเปิด เช่น "ออเดอร์ใหม่ #6909-012 · 450 บาท · รับ 12 ก.ย."
- เนื้อในใส่รายการครบ พร้อมลิงก์เข้าหลังบ้าน
- ส่งไม่สำเร็จห้ามทำให้ออเดอร์ของลูกค้าล้มเหลว
```
**ทดสอบ:** สั่ง 1 ออเดอร์ → อีเมลถึงภายในไม่กี่วินาที และอ่านหัวเรื่องแล้วรู้เรื่อง
**ถอดมาจาก:** เว็บตลาดคุณปู่ (`notify.js`)

## F3 · LINE OA — ปุ่มเพิ่มเพื่อน + Rich Menu ลิงก์เข้าเว็บ  **[ห้อง]**
**ต้องมีก่อน:** ฐาน
**แตะไฟล์:** `db.js` `public/*.html`

```
อ่าน CLAUDE.md เป็นบริบทก่อน
เพิ่มการเชื่อม LINE OA:
1. ตั้งลิงก์ LINE OA ได้จากหลังบ้าน
2. ปุ่มลอยมุมขวาล่างทุกหน้า "ทักไลน์" — บนมือถือกดแล้วเปิดแอป LINE ได้เลย
3. ปุ่ม "เพิ่มเพื่อน" ในหน้าขอบคุณหลังจองเสร็จ พร้อมข้อความว่าจะได้ข่าวสารอะไรบ้าง
4. ปุ่มลอยต้องไม่บังปุ่มสำคัญอื่น ๆ บนจอมือถือ
แล้วบอกวิธีตั้ง Rich Menu ใน LINE OA ให้กดแล้วเด้งเข้าเว็บ (เขียนเป็นขั้นตอนให้ฉันทำเอง)
```
**ทดสอบ:** เปิดบนมือถือจริง กดปุ่ม → เด้งเข้าแอป LINE
**ถอดมาจาก:** Bookly

## F4 · LINE webhook ตอบอัตโนมัติ  **[สูง]**
**ต้องมีก่อน:** F3
**แตะไฟล์:** `server.js` `.env.example` (+ `services/line.js`)

```
อ่าน CLAUDE.md เป็นบริบทก่อน
เพิ่ม webhook รับข้อความจาก LINE OA แล้วตอบอัตโนมัติ:
- POST /api/line/webhook · คีย์อ่านจาก environment variables เท่านั้น
- ต้องตรวจลายเซ็นของ LINE ก่อนเชื่อทุกครั้ง ห้ามข้าม
- ตอบอัตโนมัติ 3 อย่าง: ทักครั้งแรก → ข้อความต้อนรับ + ลิงก์เว็บ ·
  พิมพ์คำว่า "ราคา" → ลิงก์หน้ารายการ · พิมพ์เลขที่ออเดอร์ → บอกสถานะ
- อย่างอื่นให้เงียบ ปล่อยคนตอบเอง
```
**ทดสอบ:** ยิงคำขอปลอมที่ลายเซ็นผิด → ต้องถูกปฏิเสธ
**ถอดมาจาก:** Bookly (`/api/line/webhook`)

## F5 · ภาพหน้าปกตอนแชร์ลิงก์ + ชื่อบน Google  **[ห้อง]**
**ต้องมีก่อน:** ฐาน
**แตะไฟล์:** `server.js` `public/*.html` `db.js`

```
อ่าน CLAUDE.md เป็นบริบทก่อน
ตอนนี้แชร์ลิงก์เว็บเข้าไลน์แล้วขึ้นเป็นกล่องเปล่า ๆ ช่วยแก้ให้:
1. ใส่ meta tag ครบ: title, description, og:title, og:description, og:image, og:url
   ดึงค่ามาจาก content ที่แก้ได้จากหลังบ้าน
2. หน้ารายละเอียดแต่ละรายการต้องมีชื่อและรูปของตัวเอง ไม่ใช่ของหน้าแรก
   (หน้านี้โหลดข้อมูลด้วย JavaScript — ถ้าจำเป็นให้เซิร์ฟเวอร์ใส่ meta ให้ตอนส่งหน้าออกไป)
3. เพิ่ม favicon จากอีโมจิโลโก้
4. เพิ่มไฟล์ robots.txt และ sitemap.xml ที่รวมทุกหน้ารายการ
เสร็จแล้วบอกวิธีทดสอบว่าแชร์แล้วขึ้นรูปจริง
```
**ทดสอบ:** ส่งลิงก์เข้าไลน์ตัวเอง → ขึ้นรูปและชื่อร้านถูกต้อง (ถ้ายังขึ้นของเก่า ให้ลองเติม `?v=2` ท้ายลิงก์)
**ถอดมาจาก:** ใหม่ — อยู่ในเมนูงานเสริมของแผนคลาส
