## B1 · รอบเวลา + ที่นั่งเหลือ  **[ห้อง]**
**ต้องมีก่อน:** ฐาน
**แตะไฟล์:** `db.js` `server.js` `public/item.html` `public/admin.html` (+ `public/book.html`)

```
อ่าน CLAUDE.md เป็นบริบทก่อน
ทำให้แต่ละ item เปิดจองเป็นรอบได้:
1. db.js — เพิ่ม rounds ให้ item: [{ id, label, date, time, seats }]
   และเพิ่มชุดข้อมูล registrations: { id, itemId, roundId, name, phone, email, people, note, status, createdAt }
   เพิ่มฟังก์ชัน seatsTaken(itemId, roundId) นับที่นั่งที่ถูกจองไปแล้ว
2. server.js — GET /api/items/:id ต้องส่ง seatsLeft ของแต่ละรอบมาด้วย
   POST /api/register รับใบจอง และต้องปฏิเสธถ้าที่นั่งไม่พอ
3. หน้าจอง — เลือกรอบ (รอบที่เต็มให้ขึ้นว่า "เต็มแล้ว" กดไม่ได้) → กรอกชื่อ เบอร์ อีเมล จำนวนคน → ยืนยัน
4. admin.html — แท็บ "ใบจอง" ดูรายชื่อแยกตามรอบ พร้อมตัวเลขที่นั่งเหลือ
สำคัญ: การนับที่นั่งต้องนับจากใบจองจริงเสมอ ห้ามเก็บตัวเลข "ที่นั่งเหลือ" แยกไว้ต่างหาก
```
**ทดสอบ:** รอบที่มี 2 ที่ จอง 2 คน → รอบขึ้นว่าเต็ม และคนที่ 3 จองไม่ได้
**ถอดมาจาก:** Bookly (`rounds`, `seatsTaken`)

## B2 · กันที่นั่ง 24 ชั่วโมง แล้วปล่อยคืนอัตโนมัติ  **[ห้อง]**
**ต้องมีก่อน:** B1
**แตะไฟล์:** `db.js` `server.js`

```
อ่าน CLAUDE.md เป็นบริบทก่อน
เพิ่มระบบกันที่นั่งชั่วคราว:
- จองแล้วสถานะเป็น pending_payment กันที่นั่งไว้ 24 ชั่วโมง (ตั้งค่าเป็นค่าคงที่ HOLD_HOURS ใน db.js)
- ถ้าเลย 24 ชั่วโมงยังไม่แจ้งชำระเงิน ให้เปลี่ยนสถานะเป็น expired และคืนที่นั่งอัตโนมัติ
- ให้เช็กและล้างของหมดอายุทุกครั้งที่มีคนเรียกดูรายการ (ไม่ต้องตั้ง cron แยก)
- หน้าจองต้องบอกลูกค้าชัด ๆ ว่า "กันที่นั่งให้ 24 ชั่วโมง"
```
**ทดสอบ:** ตั้ง HOLD_HOURS เป็น 0.01 ชั่วคราว จองแล้วรอ 1 นาที → ที่นั่งกลับมา
**ถอดมาจาก:** Bookly (`HOLD_HOURS`, `expireStale`) — บล็อกนี้แก้ปัญหาที่คนจองแล้วหายไป แต่ที่นั่งค้างล็อก

## B4 · สมัครหลายคนในใบเดียว  **[ห้อง]**
**ต้องมีก่อน:** B1
**แตะไฟล์:** `db.js` `server.js` `public/book.html` `public/admin.html`

```
อ่าน CLAUDE.md เป็นบริบทก่อน

```
**ทดสอบ:** จอง 3 คนในใบเดียว → ที่นั่งลด 3 ไม่ใช่ 1
