# กลุ่ม C · รับเงิน

> **อ่านก่อนทำกลุ่มนี้** — ทุกบล็อกในกลุ่มนี้ยืนยันการชำระเงินด้วย **คนกดยืนยันเอง**
> ไม่มีการเชื่อม API ธนาคาร นี่เป็นการตัดสินใจโดยตั้งใจ ไม่ใช่ข้อจำกัด:
> การเชื่อมบัญชีธนาคารต้องมีสัญญากับผู้ให้บริการและมีค่าใช้จ่าย ซึ่งเกินขอบเขตของคลาสนี้

---

## C1 · QR พร้อมเพย์ฝังยอดเงิน + แนบสลิป + แอดมินกดยืนยัน  **[ห้อง]**
**ต้องมีก่อน:** A1 หรือ B1
**แตะไฟล์:** `db.js` `server.js` `public/admin.html` (+ หน้าชำระเงิน)

```
อ่าน CLAUDE.md เป็นบริบทก่อน
เพิ่มขั้นตอนชำระเงินหลังลูกค้าสั่ง/จองเสร็จ:
1. แสดง QR พร้อมเพย์ที่ฝังยอดเงินของบิลนั้นไว้แล้ว (สร้าง QR ฝั่งหน้าเว็บ)
   เอาเบอร์พร้อมเพย์และชื่อบัญชีมาจากการตั้งค่าในหลังบ้าน
2. ลูกค้าอัปโหลดสลิปได้ — ต้องย่อรูปก่อนอัปเหมือนที่ทำใน admin.html
3. สถานะเปลี่ยนเป็น awaiting_verification
4. หลังบ้านเห็นสลิป กดขยายดูได้ แล้วกด "ยืนยันรับเงิน" → สถานะเป็น paid
ห้ามให้ระบบยืนยันการชำระเงินเองโดยไม่มีคนกด
```
**ทดสอบ:** สแกน QR ด้วยแอปธนาคารจริง → ยอดเงินขึ้นตรงกับบิล
**ถอดมาจาก:** Bookly + Seed POS (`02-promptpay.js`)

---

## C2 · ตั้งค่า QR / เลขบัญชีจากหลังบ้าน  **[ห้อง]**
**ต้องมีก่อน:** C1
**แตะไฟล์:** `db.js` `server.js` `public/admin.html`

```
อ่าน CLAUDE.md เป็นบริบทก่อน
เพิ่มแท็บ "การชำระเงิน" ในหลังบ้าน ให้ตั้งค่าเองได้โดยไม่ต้องแตะโค้ด:
เบอร์พร้อมเพย์ · ชื่อบัญชี · ชื่อธนาคาร · เลขบัญชี · อัปโหลดรูป QR เอง (ถ้าอยากใช้รูปแทนการสร้าง)
· ข้อความแจ้งลูกค้าตอนโอน
หน้า public ต้องดึงค่าพวกนี้มาแสดง ถ้ายังไม่ได้ตั้งให้ขึ้นข้อความเตือนเฉพาะในหลังบ้าน
```
**ทดสอบ:** เปลี่ยนเบอร์พร้อมเพย์ในหลังบ้าน → QR ที่ลูกค้าเห็นเปลี่ยนตาม
**ถอดมาจาก:** Bookly (`payment-settings`)

## C3 · ยอดโอนสตางค์ไม่ซ้ำกัน — จับคู่สลิปได้เอง  **[บ้าน]**
**ต้องมีก่อน:** C1
**แตะไฟล์:** `db.js` `server.js`

```
อ่าน CLAUDE.md เป็นบริบทก่อน
ทำให้ยอดที่ลูกค้าต้องโอนของแต่ละบิล "ไม่ซ้ำกัน" ด้วยการเติมเศษสตางค์ 0.01–0.99
เช่น บิล 250 บาท กลายเป็น 250.37 บาท
- เศษต้องไม่ซ้ำกับบิลอื่นที่ยังรอชำระอยู่ในวันเดียวกัน
- แสดงยอดเต็มพร้อมสตางค์ทั้งในหน้าจ่ายเงิน ใน QR และในหลังบ้าน
- อธิบายให้ลูกค้าเห็นด้วยว่าทำไมต้องโอนเป๊ะ ๆ ("เพื่อให้ระบบจับคู่บิลของคุณได้")
```
**ทดสอบ:** เปิดบิลค้างพร้อมกัน 5 ใบ → สตางค์ท้ายต่างกันหมด
**ถอดมาจาก:** Seed POS — วิธีนี้ทำให้ตรวจสลิปเร็วขึ้นมาก โดยไม่ต้องต่อ API ธนาคาร

## C4 · ตรวจสลิปอัตโนมัติ (SlipOK)  **[สูง]**
**ต้องมีก่อน:** C1
**แตะไฟล์:** `server.js` `public/admin.html` `.env.example`

```
อ่าน CLAUDE.md เป็นบริบทก่อน
เพิ่มปุ่ม "ตรวจสลิปนี้" ในหลังบ้าน (ปุ่มเดียว ไม่ตรวจอัตโนมัติทุกใบ เพราะโควตาฟรีมีจำกัด)
ยิงไปที่บริการตรวจสลิปด้วยคีย์ที่อ่านจาก environment variable ชื่อ SLIPOK_KEY
ถ้ายังไม่ได้ตั้งคีย์ ให้ปุ่มยังอยู่แต่ขึ้นว่า "ยังไม่ได้ตั้งค่า" — ห้ามทำให้หน้าพัง
ผลที่ได้ให้แสดงข้าง ๆ สลิป: ยอดเงิน เวลาโอน บัญชีปลายทาง และคำเตือนถ้าไม่ตรงกับบิล
คนยังเป็นคนกดยืนยันรับเงินเหมือนเดิม ระบบแค่ช่วยอ่านให้
```
**ทดสอบ:** ยังไม่ใส่คีย์ → ปุ่มขึ้น "ยังไม่ได้ตั้งค่า" หน้าไม่พัง
**ถอดมาจาก:** Seed POS (`/api/slipcheck`)

## C5 · ชำระออนไลน์ผ่านเกตเวย์ (บัตรเครดิต)  **[สูง]**
**ต้องมีก่อน:** C1
**แตะไฟล์:** `server.js` `.env.example` (+ หน้าชำระเงิน)

```
อ่าน CLAUDE.md เป็นบริบทก่อน
เพิ่มทางเลือกจ่ายด้วยบัตรผ่านเกตเวย์ <ชื่อผู้ให้บริการ>
- คีย์ทั้งหมดอ่านจาก environment variables เท่านั้น
- มี endpoint สำหรับสร้างรายการจ่าย และ endpoint เช็กสถานะ
- ถ้ายังไม่ได้ตั้งคีย์ ให้ซ่อนตัวเลือกนี้ไปเลย เหลือแค่โอน/พร้อมเพย์
- อย่าเก็บเลขบัตรของลูกค้าไว้ในฐานข้อมูลเราเด็ดขาด
```
**ทดสอบ:** ยังไม่ใส่คีย์ → ตัวเลือกบัตรไม่โผล่ · หน้าจ่ายเงินยังใช้ได้ปกติ
**ถอดมาจาก:** Bookly (`/api/pay/card`, `/api/pay/status`)
**หมายเหตุ:** ต้องสมัครกับผู้ให้บริการและมีค่าธรรมเนียมต่อรายการ — ไม่ใช่ของฟรี
