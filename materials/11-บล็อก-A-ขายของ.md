## A1 · ตะกร้า + สั่งซื้อ + เลือกวันมารับ  **[ห้อง]**
**ต้องมีก่อน:** ฐาน
**แตะไฟล์:** `db.js` `server.js` `public/index.html` `public/item.html` `public/admin.html` (+ ไฟล์ใหม่ `public/cart.html`)

```
อ่าน CLAUDE.md เป็นบริบทก่อน
เพิ่มระบบสั่งของล่วงหน้าให้เว็บนี้:
1. db.js — เพิ่มชุดข้อมูล orders: { id, code, customerName, phone, note, items:[{itemId,name,price,qty}],
   total, pickupDate, status, createdAt } · status มีค่า new / preparing / done / cancelled
   เพิ่มฟังก์ชัน createOrder, listOrders, updateOrderStatus
2. server.js — POST /api/orders (ลูกค้าสั่ง), GET+PATCH /api/admin/orders (หลังบ้าน)
3. หน้าเว็บ — ปุ่ม "ใส่ตะกร้า" บนการ์ดในหน้าแรกและในหน้ารายละเอียด
   เก็บตะกร้าไว้ในตัวแปรบนหน้าเว็บ (อย่าใช้ localStorage) แล้วมีหน้า cart.html ให้กรอกชื่อ เบอร์
   เลือกวันมารับ แล้วกดยืนยัน
4. admin.html — เพิ่มแท็บ "ออเดอร์" แสดงตาราง กรองตามสถานะ และกดเปลี่ยนสถานะได้
อย่าเปลี่ยนชื่อ route หรือ field เดิม เสร็จแล้วบอกวิธีทดสอบ
```
**ทดสอบ:** สั่ง 2 ชิ้น → เห็นออเดอร์ในหลังบ้าน → กดเปลี่ยนสถานะเป็น done ได้
**ถอดมาจาก:** เว็บตลาดคุณปู่ (`POST /orders`, `OrderSchema`)

**ต้องมีก่อน:** A1
**แตะไฟล์:** `db.js` `public/cart.html`

```
อ่าน CLAUDE.md เป็นบริบทก่อน
ทำให้ทุกออเดอร์มีเลขที่รันอัตโนมัติแบบอ่านง่าย เช่น 6909-001 (ปีเดือน-ลำดับ)
เก็บตัวนับไว้ในฐานข้อมูลเพื่อไม่ให้เลขซ้ำแม้เซิร์ฟเวอร์รีสตาร์ท

```

**ถอดมาจาก:** เว็บตลาดคุณปู่ (`Counter` / `nextOrderCode`)

## A3 · ติดตามสถานะออเดอร์ด้วยรหัส  **[บ้าน]**
**ต้องมีก่อน:** A1, A2
**แตะไฟล์:** `server.js` (+ `public/track.html`)

```
อ่าน CLAUDE.md เป็นบริบทก่อน
ทำหน้า /track ให้ลูกค้าเอาเลขที่ออเดอร์ + เบอร์โทร มาเช็กสถานะเองได้
ต้องใช้ทั้งเลขที่และเบอร์คู่กันถึงจะเห็นข้อมูล (กันคนสุ่มเลขดูของคนอื่น)
แสดงเฉพาะ: เลขที่ สถานะ วันมารับ รายการที่สั่ง ยอดรวม — ห้ามแสดงเบอร์หรือชื่อเต็มของลูกค้า
```
**ทดสอบ:** ใส่เลขถูกเบอร์ผิด → ต้องไม่เห็นข้อมูล
**ถอดมาจาก:** Best Brew (`app/order/[code]`)

**ต้องมีก่อน:** A1
**แตะไฟล์:** `db.js` `public/item.html` `public/cart.html` `public/admin.html`

```
อ่าน CLAUDE.md เป็นบริบทก่อน

บันทึก addons ที่เลือกลงไปในออเดอร์ด้วย และแสดงในตารางหลังบ้าน

**ถอดมาจาก:** Bookly (`addons`) · Seed POS (toppings)

**แตะไฟล์:** `db.js` `server.js`

```

## A6 · สต๊อก + แจ้งเตือนของใกล้หมด + ปิดขายเมื่อหมด  **[สูง]**
**ต้องมีก่อน:** A1
**แตะไฟล์:** `db.js` `server.js` `public/admin.html` `public/index.html`

```
อ่าน CLAUDE.md เป็นบริบทก่อน
เพิ่มระบบสต๊อกแบบง่าย:
- แต่ละ item มี stock (จำนวนคงเหลือ) และ lowAlert (จุดเตือน) แก้ได้จากหลังบ้าน
- สั่งซื้อสำเร็จให้หักสต๊อก · ยกเลิกออเดอร์ให้คืนสต๊อก
- ถ้า stock = 0 การ์ดขึ้นว่า "ของหมด" และกดสั่งไม่ได้
- หน้าหลังบ้านมีกล่องรวม "ของใกล้หมด" ที่ต่ำกว่า lowAlert
อย่าให้สต๊อกติดลบไม่ว่ากรณีใด
```
**ทดสอบ:** ตั้งสต๊อก 1 แล้วสั่ง 2 คนพร้อมกัน → ต้องมีคนหนึ่งสั่งไม่ได้ ไม่ใช่ติดลบ
**ถอดมาจาก:** Seed POS (`04-stock.js`)
