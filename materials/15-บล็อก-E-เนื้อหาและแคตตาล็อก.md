# กลุ่ม E · เนื้อหา / แคตตาล็อก

---

## E1 · แคตตาล็อก + ฟิลเตอร์หลายเงื่อนไขพร้อมกัน  **[ห้อง]**
**ต้องมีก่อน:** ฐาน
**แตะไฟล์:** `db.js` `public/index.html` `public/admin.html`

```
อ่าน CLAUDE.md เป็นบริบทก่อน
เพิ่มระบบหมวดหมู่และฟิลเตอร์ให้หน้าแรก:
1. item มี cat (หมวด) และ tags (ป้ายหลายอัน) แก้ได้จากหลังบ้าน
2. หน้าแรกมีแถบหมวดด้านบน + ตัวกรองด้านข้าง ที่ติ๊กหลายเงื่อนไขพร้อมกันได้
   เงื่อนไขที่ฉันอยากกรองคือ: <ระบุ เช่น ราคา / ขนาด / สี / ความยาก>
3. กรองแล้วต้องไม่โหลดหน้าใหม่ — กรองจากข้อมูลที่โหลดมาแล้ว
4. มีปุ่ม "ล้างตัวกรอง" และแสดงจำนวนที่เจอ
5. ถ้ากรองแล้วไม่เจอ ให้ขึ้นข้อความแนะนำ ไม่ใช่หน้าว่าง
```
**ทดสอบ:** ติ๊ก 3 เงื่อนไขพร้อมกัน → ผลลัพธ์ตรงทุกเงื่อนไข ไม่ใช่ตรงแค่อันเดียว
**ถอดมาจาก:** แคตตาล็อก Always Trees (กรองพร้อมกัน 8 เงื่อนไข)

## E2 · ซ่อนราคา — แยกข้อมูลสาธารณะกับข้อมูลภายในด้วยโครงสร้าง  **[ห้อง]**
**ต้องมีก่อน:** ฐาน
**แตะไฟล์:** `db.js` `server.js` `public/admin.html`

```
อ่าน CLAUDE.md เป็นบริบทก่อน
ร้านฉันไม่โชว์ราคาบนเว็บ ลูกค้าต้องทักมาถาม แต่ฉันต้องเก็บราคาต้นทุน/ราคาขายไว้ดูเอง
ขอให้กันด้วยโครงสร้าง ไม่ใช่ด้วยการซ่อนบนหน้าเว็บ:
- แยกข้อมูลเป็นสองชุด: ชุดสาธารณะ (ไม่มีช่องราคาอยู่เลย) กับชุดภายใน (มีราคา) เชื่อมกันด้วย id
- API ฝั่ง public ต้องไม่มีทางส่งราคาออกไปได้ แม้จะมีคนเรียก /api/site ตรง ๆ
- หลังบ้านเห็นราคาได้ตามปกติ
- แทนที่ปุ่มราคาด้วยปุ่ม "สอบถามราคา" ที่ลิงก์ไป LINE
เสร็จแล้วบอกวิธีทดสอบว่าราคาไม่หลุดจริง
```
**ทดสอบ:** เปิด `/api/site` ในเบราว์เซอร์ตรง ๆ แล้วค้นคำว่า price → ต้องไม่เจอ
**ถอดมาจาก:** แคตตาล็อก Always Trees — กฎเหล็กของโปรเจกต์นั้นคือ "ราคาต้องไม่หลุดขึ้นเว็บ"

## E3 · เว็บไฟล์เดียว ไม่ต้องมีเซิร์ฟเวอร์  **[ห้อง]**
**ต้องมีก่อน:** ไม่มี (ใช้แทนฐานไปเลย)
**แตะไฟล์:** ไฟล์ใหม่ล้วน

> ทางลัดสำหรับคนที่แค่อยากมีเว็บโชว์ของ ไม่ต้องเก็บข้อมูลลูกค้า — ขึ้นออนไลน์ได้ใน 10 นาที

```
อ่าน CLAUDE.md เป็นบริบทก่อน แล้วทำเวอร์ชันย่อของเว็บนี้:
สร้างเป็น HTML ไฟล์เดียวที่มี CSS และ JS อยู่ในไฟล์เดียวกัน
ข้อมูลรายการอ่านจากไฟล์ data.json ที่อยู่ข้าง ๆ กัน
มีหน้าแรก การ์ดรายการ ฟิลเตอร์ และหน้ารายละเอียดแบบ popup
ไม่มีหลังบ้าน ไม่มีฐานข้อมูล ไม่ต้องติดตั้งอะไร — ดับเบิลคลิกเปิดได้เลย
แล้วบอกวิธีเอาขึ้นออนไลน์ฟรีโดยไม่ต้องใช้ Render
```
**ทดสอบ:** ดับเบิลคลิกไฟล์บนเครื่อง → เว็บทำงานครบ
**ถอดมาจาก:** แคตตาล็อก Always Trees (`always-trees-catalogue.html`)

---

## E4 · แก้ข้อมูลในหน้าเว็บเอง + Export กลับเป็นไฟล์  **[บ้าน]**
**ต้องมีก่อน:** E3
**แตะไฟล์:** ไฟล์เว็บไฟล์เดียว

```
อ่าน CLAUDE.md เป็นบริบทก่อน
ในเว็บไฟล์เดียว เพิ่มโหมดแก้ไขที่เปิดด้วยการเติม ?edit ท้ายลิงก์:
- แก้ข้อมูลแต่ละรายการได้ในหน้าเว็บเลย เพิ่ม/ลบรายการได้
- แก้เสร็จกดปุ่ม "ดาวน์โหลด data.json" แล้วเอาไฟล์ใหม่ไปทับของเดิม
- โหมดนี้ห้ามส่งข้อมูลไปไหนทั้งสิ้น ทำงานในเครื่องล้วน ๆ
- คนที่ไม่ได้เติม ?edit ต้องไม่เห็นปุ่มแก้ไขเลย
```
**ทดสอบ:** แก้ 3 รายการ → ดาวน์โหลด → ทับไฟล์เดิม → รีเฟรช ข้อมูลใหม่อยู่ครบ
**ถอดมาจาก:** แคตตาล็อก Always Trees (ปุ่มแก้ไข + export)

## E5 · หน้า "เกี่ยวกับเรา" + แผนที่ + เวลาเปิด–ปิด  **[ห้อง]**
**ต้องมีก่อน:** ฐาน
**แตะไฟล์:** `db.js` `public/index.html` (+ `public/about.html`)

```
อ่าน CLAUDE.md เป็นบริบทก่อน
ทำหน้า /about แยกออกมาให้เต็ม ๆ แทนที่จะเป็นแค่ส่วนหนึ่งของหน้าแรก:
- เรื่องราวของร้าน + รูปได้หลายรูป (แก้จากหลังบ้าน)
- แผนที่ฝังจาก Google Maps + ปุ่ม "นำทาง"
- ตารางเวลาเปิด–ปิดรายวัน และแสดงว่า "ตอนนี้เปิดอยู่ / ปิดแล้ว" ตามเวลาจริง
- ปุ่มโทรและปุ่มทัก LINE ที่กดจากมือถือแล้วใช้ได้ทันที
```
**ทดสอบ:** เปลี่ยนเวลาในเครื่องให้เป็นนอกเวลาทำการ → ขึ้นว่า "ปิดแล้ว"
**ถอดมาจาก:** ใหม่ — อยู่ในเมนูงานเสริมของแผนคลาส

## E6 · สองภาษา ไทย/อังกฤษ สลับได้  **[บ้าน]**
**ต้องมีก่อน:** ฐาน
**แตะไฟล์:** `db.js` `public/*.html` `public/admin.html`

```
อ่าน CLAUDE.md เป็นบริบทก่อน
ทำให้เว็บสลับภาษาไทย/อังกฤษได้:
- ข้อความใน content และชื่อ/รายละเอียดของ item เก็บเป็นคู่ { th, en }
- หลังบ้านมีช่องกรอกสองภาษาคู่กัน
- ปุ่มสลับภาษาอยู่มุมขวาบน จำค่าที่เลือกไว้ระหว่างหน้า
- ถ้าภาษาอังกฤษยังไม่ได้กรอก ให้แสดงภาษาไทยแทน อย่าโชว์ช่องว่าง
ข้อมูลเดิมที่มีอยู่ต้องไม่หาย — แปลงเป็น { th: <ค่าเดิม>, en: "" } ให้อัตโนมัติ
```
**ทดสอบ:** ข้อมูลเก่ายังแสดงครบหลังเปลี่ยนโครงสร้าง
**ถอดมาจาก:** เว็บตลาดคุณปู่ (`Bi` = bilingual field)

## E7 · เข้าถึงง่าย — ตัวอักษร 3 ขนาด + โหมดมืด  **[ห้อง]**
**ต้องมีก่อน:** ฐาน
**แตะไฟล์:** `public/css/styles.css` `public/*.html`

```
อ่าน CLAUDE.md เป็นบริบทก่อน
เพิ่มปุ่มปรับขนาดตัวอักษร 3 ระดับ (ปกติ / ใหญ่ / ใหญ่มาก) ไว้มุมขวาบน
สำหรับลูกค้าสูงอายุ — ต้องขยายทั้งหน้ารวมถึงปุ่มและช่องกรอก ไม่ใช่แค่ตัวหนังสือ
และรองรับโหมดมืดตามการตั้งค่าของเครื่องผู้ใช้ (prefers-color-scheme)
โหมดมืดต้องอ่านง่ายจริง ๆ ไม่ใช่แค่กลับสีขาวดำ — ตรวจว่าตัวหนังสือกับพื้นหลังตัดกันพอ
จำค่าที่ผู้ใช้เลือกไว้ในตัวแปรบนหน้า (อย่าใช้ localStorage)
```
**ทดสอบ:** ขนาดใหญ่มาก + จอมือถือ → ไม่มีตัวหนังสือทับกันหรือล้นออกนอกจอ
**ถอดมาจาก:** เว็บตลาดคุณปู่ (ปุ่มขนาดตัวอักษร 3 ระดับ + โหมดมืด)
