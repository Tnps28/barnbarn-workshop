# 🌿 BARNBARN Workshop — ระบบจัดการเวิร์กช็อป

ระบบเว็บสำหรับเปิดรับสมัครเวิร์กช็อป รับชำระเงินออนไลน์ (พร้อมเพย์ + บัตร) และส่งข้อความยืนยันผ่าน LINE Official Account
พร้อมหน้าผู้ดูแลสำหรับเพิ่มเวิร์กช็อป ตั้งวัน/รอบ และติดตามการสมัคร–ชำระเงิน–ยืนยัน

A full web app to open workshop registration, collect online payments (PromptPay + card), and send confirmations via LINE Official Account — with an organizer admin panel to add workshops, set dates/rounds, and track registration → payment → confirmation.

---

## สิ่งที่ได้ / What you get

- **หน้าเว็บผู้สมัคร (ภาษาไทย)** — ดูเวิร์กช็อป เลือกรอบ กรอกข้อมูล ชำระเงิน แล้วรับรหัสอ้างอิง
- **ชำระเงินออนไลน์จริง** — ผ่าน Omise (พร้อมเพย์ QR + บัตรเครดิต/เดบิต) มาตรฐานที่ใช้กันในไทย
- **หน้าผู้ดูแล** — เพิ่ม/แก้ไขเวิร์กช็อป ตั้งวัน–รอบ–ที่นั่ง–ราคา ดูรายชื่อผู้สมัคร ทำเครื่องหมายชำระแล้ว และส่งยืนยัน LINE
- **ยืนยันผ่าน LINE OA** — ส่งอัตโนมัติ (ถ้าเชื่อม Messaging API) หรือคัดลอกข้อความไปส่งเองก็ได้
- **กันที่นั่งเกิน** — ระบบนับที่นั่งตามจำนวนคนต่อรอบให้อัตโนมัติ

> 💡 รันได้ทันทีในโหมดทดลอง (Demo) โดยไม่ต้องมีคีย์ใด ๆ — เพื่อให้คุณเห็นทั้งระบบก่อน แล้วค่อยใส่คีย์จริงภายหลัง

## 1) เริ่มใช้งานในเครื่อง / Quick start (local)

ต้องมี **Node.js 18 ขึ้นไป** (ดาวน์โหลด: https://nodejs.org)

```bash
cd barnbarn-workshop
npm install
npm start
```

เปิดเบราว์เซอร์:
- หน้าผู้สมัคร: **http://localhost:3000**
- หน้าผู้ดูแล: **http://localhost:3000/admin**  (รหัสผ่านเริ่มต้น: `barnbarn2026`)

ตอนนี้ระบบทำงานแบบ **Demo** — สมัคร/กดจ่ายได้ครบทุกขั้น แต่ยังไม่ตัดเงินจริง และยังไม่ส่ง LINE จริง

---

## 2) ตั้งค่าให้ใช้งานจริง / Configuration

คัดลอก `.env.example` เป็น `.env` แล้วแก้ค่า:

```bash
cp .env.example .env
```

| ค่า | ความหมาย |
|---|---|
| `ADMIN_PASSWORD` | รหัสผ่านหน้าผู้ดูแล — **เปลี่ยนทันที** |
| `PUBLIC_BASE_URL` | ลิงก์เว็บจริงของคุณ เช่น `https://workshop.barnbarn.com` |
| `OMISE_PUBLIC_KEY` / `OMISE_SECRET_KEY` | คีย์รับชำระเงิน (ดูข้อ 3) |
| `LINE_CHANNEL_ACCESS_TOKEN` | โทเคนส่งข้อความ LINE (ดูข้อ 4) |
| `LINE_ADD_FRIEND_URL` | ลิงก์เพิ่มเพื่อน LINE OA ของคุณ |

> เว้นค่าใดว่างไว้ = ส่วนนั้นทำงานโหมด Demo/manual — ระบบยังรันได้ปกติ

---

## 3) เชื่อมรับชำระเงิน (Omise) / Payments

1. สมัครบัญชีที่ **https://dashboard.omise.co** (ฟรี รองรับพร้อมเพย์และบัตร)
2. ไปที่ **Keys** จะเห็นคีย์ 2 ชุด: *test* (ขึ้นต้น `_test_`) และ *live* (`_live_`)
3. ทดสอบก่อนด้วยชุด **test** — ใส่ใน `.env`:
   ```
   OMISE_PUBLIC_KEY=pkey_test_xxxxx
   OMISE_SECRET_KEY=skey_test_xxxxx
   ```
4. เลขบัตรทดสอบ Omise: `4242 4242 4242 4242` วันหมดอายุอนาคตใด ๆ / CVV อะไรก็ได้
5. พร้อมเปิดจริง → เปลี่ยนเป็นคีย์ `_live_` (ต้องยืนยันตัวตนธุรกิจกับ Omise ก่อน)

การจ่ายพร้อมเพย์: ระบบสร้าง QR ให้ผู้สมัครสแกน แล้ว **ตรวจสอบสถานะอัตโนมัติทุก 4 วินาที** เมื่อจ่ายสำเร็จหน้าเว็บจะขึ้น “สมัครสำเร็จ” เอง

---

## 4) เชื่อม LINE Official Account / LINE confirmation

1. สร้าง OA ที่ **https://manager.line.biz** แล้วเปิด Messaging API
2. ไปที่ **https://developers.line.biz** → เลือก channel → **Messaging API**
3. คัดลอก **Channel access token (long-lived)** ใส่ใน `.env`:
   ```
   LINE_CHANNEL_ACCESS_TOKEN=xxxxx
   ```
4. ใส่ลิงก์เพิ่มเพื่อน OA ของคุณใน `LINE_ADD_FRIEND_URL`
5. (ถ้าต้องการส่งอัตโนมัติ) ตั้ง **Webhook URL** เป็น `https://<เว็บของคุณ>/api/line/webhook`
   เมื่อผู้สมัครทักแชทพร้อมรหัสอ้างอิง (`reg_xxxx`) ระบบจะจับคู่ LINE userId ให้เอง แล้วปุ่ม “ส่งยืนยัน LINE” จะส่งข้อความถึงเขาโดยตรง

> ยังไม่เชื่อม LINE ก็ใช้งานได้ — กด “ส่งยืนยัน LINE” แล้วระบบจะสร้างข้อความสำเร็จรูปให้ **คัดลอกไปส่งเองในแอป LINE OA**

---

## 5) เอาขึ้นออนไลน์ให้คนเข้าถึงได้ / Deploy online

ต้องมีเซิร์ฟเวอร์รัน Node ตลอดเวลา วิธีง่ายที่สุด (มีแพ็กฟรี):

**Render.com** (แนะนำสำหรับผู้เริ่มต้น)
1. อัปโหลดโฟลเดอร์นี้ขึ้น GitHub
2. Render → New → **Web Service** → เชื่อม repo
3. Build command: `npm install` · Start command: `npm start`
4. ใส่ค่าจาก `.env` ในหน้า **Environment**
5. ได้ลิงก์ `https://xxx.onrender.com` — เอาไปแชร์/ใส่ในไบโอ LINE ได้เลย

ทางเลือกอื่น: **Railway.app**, **Fly.io**, หรือ VPS ทั่วไป (ใช้ `pm2` ให้รันค้าง)

> ⚠️ ข้อมูลเก็บในไฟล์ `data/db.json` — บนโฮสต์ที่ล้าง disk (เช่น Render free) ควรต่อ **Persistent Disk** หรือย้ายไปฐานข้อมูลจริงภายหลัง เพื่อไม่ให้ข้อมูลหาย

---

## 6) ขั้นตอนการทำงานประจำวันของผู้จัด / Daily workflow

1. เพิ่มเวิร์กช็อปใหม่ในหน้าผู้ดูแล → ตั้งชื่อ วัน–รอบ ที่นั่ง ราคา รายละเอียด
2. แชร์ลิงก์หน้าแรกให้ผู้สนใจสมัคร
3. ผู้สมัครกรอกข้อมูล + จ่ายเงิน → รายการขึ้นในตาราง “รายชื่อผู้สมัคร”
   - จ่ายผ่านระบบสำเร็จ → สถานะขึ้น **ชำระแล้ว** อัตโนมัติ
   - โอนนอกระบบ → กด **“ทำเครื่องหมายชำระแล้ว”** เอง
4. กด **“ส่งยืนยัน LINE”** เพื่อยืนยันที่นั่ง (อัตโนมัติหรือคัดลอกส่งเอง)
5. ดูภาพรวมยอดสมัคร/รายรับได้จากการ์ดสถิติด้านบน

## โครงสร้างไฟล์ / Project structure

```
barnbarn-workshop/
├── server.js            # เซิร์ฟเวอร์ + API ทั้งหมด
├── db.js                # ที่เก็บข้อมูล (ไฟล์ JSON, ไม่ต้องมี DB แยก)
├── services/
│   ├── payment.js       # เชื่อม Omise (พร้อมเพย์ + บัตร)
│   └── line.js          # ส่งข้อความยืนยัน LINE
├── public/
│   ├── index.html       # หน้าแรก (รายการเวิร์กช็อป)
│   ├── workshop.html    # รายละเอียด + สมัคร + ชำระเงิน
│   ├── admin.html       # หน้าผู้ดูแล
│   └── css/styles.css   # ธีมธรรมชาติ อบอุ่น
├── .env.example         # ตัวอย่างการตั้งค่า
└── data/db.json         # ข้อมูลจริง (สร้างอัตโนมัติ)
```

## หมายเหตุความปลอดภัย / Security notes

- เปลี่ยน `ADMIN_PASSWORD` ก่อนเปิดใช้จริงเสมอ
- ใช้ HTTPS เมื่อ deploy (Render/Railway ให้มาอัตโนมัติ) โดยเฉพาะหน้าชำระเงิน
- ข้อมูลบัตรถูกส่งตรงจากเบราว์เซอร์ไป Omise ผ่าน Omise.js — **ไม่ถูกเก็บบนเซิร์ฟเวอร์ของคุณ**
- สำรองไฟล์ `data/db.json` เป็นระยะ
